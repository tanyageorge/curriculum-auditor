Curriculum Auditor

Find the prerequisites your course catalog gets wrong.

Muse Spark reads every prerequisite in a university catalog and maps it as a graph. Then code checks that graph for courses that require themselves, loops, and requirements on courses that no longer exist.

Open the app See a catalog with problems

Tested on 150 hand-labeled courses: 94.7% parsed exactly right, against 80.7% for a rule-based parser. 21,739 courses audited across 14 universities.

  1. Pick a university from the menu at the top of the app.
  2. Click a finding to see the catalog text it came from.
  3. Follow the graph: click any course in it to walk the chain.

    How well it works

    Every number on this page comes from a test run saved in the repository. The headline accuracy figure is based on 150 hand-labeled courses, scored once at the end.

    How it works

    The model reads the catalog; deterministic code verifies the results. Anything that must be exact is done in code.

    1. Start with the catalog textEach course's prerequisite text is used exactly as the university published it.
    2. Muse Spark reads itMuse Spark 1.3 turns each sentence into AND/OR logic in a fixed JSON format: which courses, which ones are alternatives, which can be taken at the same time, and any minimum grade. If a sentence is unclear, it flags it instead of guessing.
    3. Code verifies itEvery course in Muse Spark's output must appear in the source text. If one doesn't, the exact problem is sent back for one retry; if it still fails, the course is flagged for human review.
    4. A second opinionMuse Spark Open, the open-weights version, was run on Baseten to test whether a second model catches additional errors. It largely made the same mistakes, so it added little; the result is reported as a finding.
    5. Build the graph and check itEvery course is linked to its prerequisites, and the graph is checked for courses that require themselves, loops, required courses that don't exist, and courses that were renumbered.
    6. Report the findingsFindings are generated by code, not by the model, so each one cites the exact catalog text it is based on.

    Meta models used

    • Muse Spark 1.3 on the Meta Model API reads every prerequisite.
    • Muse Spark Open (open weights, on Baseten) served as the second-opinion test.

    Where the data comes from

    • 13 catalogs come from a public research dataset: Turaev et al., A Confound-Annotated Multi-Institution Curriculum Dataset with Parsed Prerequisite Logic (Mendeley Data, CC BY 4.0). These are shown with the dataset's own parsed prerequisites, so any errors in it carry over.
    • The UIUC Spring 2026 catalog (Kaggle, from Wade Fagen-Ulmschneider's UIUC data, CC BY-SA 4.0) was parsed by Muse Spark for this project.
