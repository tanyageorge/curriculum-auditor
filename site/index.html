Curriculum Auditor
Built with Meta Muse Spark · Meta Global AI Developer Hackathon

Find the broken prerequisites hiding in a course catalog.

Universities write prerequisites as sentences, so nobody sees the whole picture. Curriculum Auditor reads every one with Muse Spark, turns it into exact AND/OR logic, and checks the whole catalog in code for courses that require themselves, prerequisite loops, and requirements on courses that no longer exist.

How to use it

  1. Pick a catalogChoose a university from the menu. UIUC was parsed by Muse Spark for this project; the other 13 come from a public research dataset.
  2. Scan the findingsEach card is one problem, with its severity and the exact catalog text it's based on. Filter by type with the chips, or search for a course code.
  3. Open a courseClick a finding or search a code to see the catalog text, the parsed AND/OR logic, and its prerequisite graph. Click any course in it to follow the chain.

How it works

The model reads; code verifies. Anything that must be exact is done in code.

  1. Catalog textPrerequisite and corequisite text exactly as printed.
  2. Parse: Muse Spark 1.3Meta Model API, strict JSON schema: AND/OR groups, timing, grades, conditions. Ambiguous text is flagged, not guessed.
  3. Guardrails in codeEvery course in the output must appear in the input text. On failure the model gets the exact problem back for one retry, then the course is flagged for review.
  4. Second opinion: Muse Spark OpenOpen weights on Baseten, compared against Muse Spark. Measured: same-family models fail together, so it adds little; reported honestly.
  5. Audit in codePrerequisite graph with networkx; checks for self-reference, loops through required courses, missing and renumbered courses, long chains. Severity: blocking, warning, info.
  6. ReportGenerated from the findings, not by a model, so every line cites a finding ID and the catalog text behind it.

Meta models used

  • Muse Spark 1.3 via the Meta Model API: the primary parser
  • Muse Spark Open (open weights) via Baseten: the independent second parser

Data

  • Turaev et al., A Confound-Annotated Multi-Institution Curriculum Dataset with Parsed Prerequisite Logic, Mendeley Data, CC BY 4.0: 13 catalogs, shown with that dataset's published parses
  • UIUC Course Catalog, Spring 2026 (Kaggle; Wade Fagen-Ulmschneider's UIUC data), CC BY-SA 4.0: parsed by Muse Spark here; derived data shared under CC BY-SA 4.0
